# Workshop 14: AI for Shift Handover, Daily Reports, and Issue Summaries

Duration: 60 minutes

Audience: Production, Maintenance, Quality, Logistics, Planning, Plant Management

## Purpose

Help teams turn messy operational notes into clear handovers, daily reports, issue summaries, and manager briefs.

## 60-Minute Agenda

- 0-5 min: Explain why structured handovers reduce errors.
- 5-15 min: Create a shift handover.
- 15-25 min: Extract open actions.
- 25-35 min: Create a manager summary.
- 35-45 min: Identify missing information.
- 45-55 min: Build a reusable template.
- 55-60 min: Save the template.

## Exercise 1: Create a Shift Handover

Time: 10 minutes

Prompt:

```text
Turn these rough shift notes into a structured handover with: summary, production status, quality issues, maintenance issues, safety notes, open actions, owner, deadline, next shift priorities, and missing information.
```

Output: structured shift handover.

## Exercise 2: Extract Open Actions

Time: 10 minutes

Prompt:

```text
Extract all open actions from this report. Return a table with action, owner, deadline, priority, risk if not completed, and information missing.
```

Output: action tracker.

## Exercise 3: Create a Manager Summary

Time: 10 minutes

Prompt:

```text
Create a manager summary from this operational report. Include key result, main problems, impact, decisions needed, and next 24-hour priorities.
```

Output: short manager brief.

## Exercise 4: Identify Missing Information

Time: 10 minutes

Prompt:

```text
Review this shift report and identify missing facts, unclear ownership, incomplete timestamps, unclear machine or line references, and items requiring verification.
```

Output: missing information list.

## Exercise 5: Build a Daily Report Template

Time: 10 minutes

Task: Create a reusable report template for the department.

Recommended sections:

- date and shift
- line or area
- output/status
- issues
- root cause if known
- action taken
- open actions
- support needed
- safety or quality notes

Output: department daily report template.
