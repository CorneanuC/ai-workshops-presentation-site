# Workshop 08: AI for Excel, Data, and Decision Support

Duration: 60 minutes

Audience: HR, Clients/Customer Service, Finance

## Purpose

Help employees use AI to understand tables, create formulas, summarize trends, and prepare decision support without losing control of the data.

## 60-Minute Agenda

- 0-5 min: Explain anonymization and data checking before using AI.
- 5-55 min: Five practical exercises.
- 55-60 min: Save data prompts and verification rules.

## Exercise 1: Ask for Useful Analyses

Time: 10 minutes

Prompt:

```text
I have a table with these columns: [paste column names only]. Suggest 5 useful analyses and explain what each analysis would show.
```

HR:
- employee_id_removed, department, training_name, attendance_status, score, date

Clients/Customer Service:
- ticket_id, category, response_time, status, satisfaction_score, date

Finance:
- invoice_id, supplier, amount, cost_center, approval_status, due_date

Output: 5 analysis ideas.

## Exercise 2: Generate Excel Formulas

Time: 10 minutes

Prompt:

```text
Suggest Excel formulas for the analysis below. Explain each formula in simple language.
```

HR:
- Count completed trainings by department.

Clients/Customer Service:
- Average response time by category.

Finance:
- Total overdue invoice amount by supplier.

Output: Formula suggestions.

## Exercise 3: Summarize a Small Table

Time: 10 minutes

Task: Use a small anonymized sample table.

Prompt:

```text
Summarize this table. Identify trends, outliers, and questions a manager should ask. Do not change the numbers.
```

HR:
- Training attendance sample.

Clients/Customer Service:
- Ticket resolution sample.

Finance:
- Invoice approval sample.

Output: Data summary.

## Exercise 4: Create a Manager Brief

Time: 10 minutes

Prompt:

```text
Turn this data summary into a manager brief with: key finding, impact, possible cause, recommended next step, and data to verify.
```

HR:
- Training completion risk.

Clients/Customer Service:
- Slow response category.

Finance:
- Overdue invoices.

Output: Manager brief.

## Exercise 5: Verify AI Data Output

Time: 10 minutes

Prompt:

```text
Review your own analysis and list all calculations, assumptions, and conclusions that need manual verification.
```

Output: Data verification checklist.
