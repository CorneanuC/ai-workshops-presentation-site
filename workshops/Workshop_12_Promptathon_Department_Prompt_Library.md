# Workshop 12: Prompt-a-thon: Build Your Department Prompt Library

Duration: 60 minutes

Audience: All factory departments

## Purpose

Create a practical prompt library that departments can use immediately after the workshop.

## 60-Minute Agenda

- 0-5 min: Explain prompt quality criteria.
- 5-15 min: Build one document prompt.
- 15-25 min: Build one email prompt.
- 25-35 min: Build one data prompt.
- 35-45 min: Build one review prompt.
- 45-55 min: Test and improve prompts.
- 55-60 min: Save approved prompts.

## Prompt Quality Formula

```text
Role + Task + Context + Input + Format + Constraints + Verification
```

## Exercise 1: Document Prompt

Time: 10 minutes

Task: Create a prompt for improving a department document.

Examples:

- HR: onboarding checklist
- Production: daily production report
- Quality: nonconformity report
- Maintenance: breakdown report
- Logistics: delivery issue summary
- Finance: invoice clarification
- Customer Service: complaint summary

Output: One document prompt.

## Exercise 2: Email Prompt

Time: 10 minutes

Task: Create a prompt for writing or improving an email.

Required constraints:

```text
Keep facts unchanged.
Do not invent commitments.
Flag missing information.
Use a professional tone.
```

Output: One email prompt.

## Exercise 3: Data Prompt

Time: 10 minutes

Task: Create a prompt for understanding a table or KPI.

Example:

```text
Act as a factory performance analyst. Review this anonymized KPI table. Identify trends, outliers, possible causes, and questions for the manager. Do not change numbers.
```

Output: One data prompt.

## Exercise 4: Review Prompt

Time: 10 minutes

Task: Create a prompt for checking accuracy before sending a document.

Required checks:

- missing information
- contradictions
- unclear wording
- numbers and dates
- commitments
- human verification needed

Output: One review prompt.

## Exercise 5: Test and Improve

Time: 10 minutes

Task: Test each prompt on a realistic sample and improve it.

Review questions:

- Was the output useful?
- Was the format correct?
- Did AI invent anything?
- What must a human verify?
- Can a colleague reuse the prompt easily?

Output: 3-5 approved prompts per department.
