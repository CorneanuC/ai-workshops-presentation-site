# Workshop 02: Prompting Skills

Duration: 60 minutes

Audience: HR, Clients/Customer Service, Finance

## Purpose

Teach employees how to write clear prompts that produce useful, structured, and verifiable outputs.

## 60-Minute Agenda

- 0-5 min: Introduce the prompt formula: Role + Task + Context + Format + Constraints.
- 5-55 min: Five practical exercises.
- 55-60 min: Save the best prompts into the prompt library.

## Exercise 1: Improve a Weak Prompt

Time: 10 minutes

Weak prompt:

```text
Make this better.
```

Task: Rewrite it using the prompt formula.

HR:

```text
Act as an HR communication assistant. Rewrite this employee announcement to be clear, respectful, and concise. Keep the meaning unchanged. Return one formal version and one simple version.
```

Clients/Customer Service:

```text
Act as a customer service advisor. Rewrite this customer reply to sound professional, empathetic, and clear. Do not promise compensation unless it is stated in the original note.
```

Finance:

```text
Act as a finance analyst. Rewrite this budget explanation for a non-finance manager. Keep all numbers unchanged and highlight any unclear assumptions.
```

Output: One improved prompt per department.

## Exercise 2: Add Context

Time: 10 minutes

Task: Add business context so AI understands the situation.

HR:
- Context: factory shift workers, internal training, simple language.

Clients/Customer Service:
- Context: delayed order, frustrated client, company policy must be respected.

Finance:
- Context: monthly closing, cost center review, manager audience.

Output: A context-rich prompt.

## Exercise 3: Specify the Format

Time: 10 minutes

Task: Ask AI to return output as a table.

Prompt:

```text
Return the answer as a table with these columns: issue, why it matters, suggested improvement, human verification needed.
```

HR:
- Review an onboarding checklist.

Clients/Customer Service:
- Review a customer email draft.

Finance:
- Review an expense explanation.

Output: A structured review table.

## Exercise 4: Set Boundaries

Time: 10 minutes

Task: Add constraints that prevent unsafe or invented output.

Useful constraints:

```text
Do not invent facts.
Keep numbers unchanged.
Flag uncertain points.
Ask questions where information is missing.
Use only the information provided.
```

HR:
- Avoid employment law advice.

Clients/Customer Service:
- Avoid commitments not approved by policy.

Finance:
- Avoid changing figures or assumptions.

Output: A safer prompt with clear boundaries.

## Exercise 5: Create a Reusable Prompt

Time: 10 minutes

Task: Create one prompt your department can use weekly.

HR:
- Training invitation or onboarding plan prompt.

Clients/Customer Service:
- Complaint summary or reply improvement prompt.

Finance:
- Variance explanation or invoice issue prompt.

Output: One approved prompt for the AI Prompt Library.
